| | 第一版 | 第二版 |
|---|---|---|
| 两条碎句之间 | 约 23px（比一行行高还小） | 1440 宽约 61px，手机约 44px |
| 行宽 | 每行约 38 字 | 每行至多 30 字（`max-width: 30em`） |

| 底色 | 水彩纸渐变 + 噪点 / 星空 | 纯色一张纸：浅色 `#f6f1e7`，深色 `#16181d`，不再有星空层和纸纹 |

## 母题：纸飞机

**决定**：用用户举例的纸飞机。
- 考虑过：蒲公英种子（飘散、轻，但和「被炸号后捡回来的句子」联系弱）、信封/邮戳（贴合「写给谁的话」，但画面偏重）、一根铅笔线（太抽象，不像线索）。
- 选纸飞机的理由：这些句子本来就是随手写、随手扔出去的话，像一张纸折成飞机掷出去；飞机带一条虚线航迹，天然可以当「线索」把一章章串起来；造型极简，单线就能画，和插画的墨线笔触不冲突。

**同一个来源**：页面顶部一个 `<symbol id="plane">`，全页每一只纸飞机都是 `<use href="#plane">`，颜色统一用一支「蓝墨水」（浅色 `#4f6f8f`，深色 `#9fbad6`），与黑色墨线插画区分开。用途（`data-motif` 值）：

1. `hero` 刊头：一段打了个圈的虚线航迹，纸飞机停在末端轻轻浮动；
2. `section` 小节标记：每个小节标题上方一只小纸飞机；
3. `trail` 章末分隔：每章结尾一段虚线航迹，纸飞机飞向下一章；
4. `progress` 阅读进度：屏幕顶上一根虚线，纸飞机随阅读进度从左飞到右；
5. `music` 音乐开关：播放时纸飞机抬头「起飞」；
6. `top` 回到顶部：滚过一屏后出现在右下角，纸飞机朝上；
7. `end` 页尾：最后一段航迹，飞机落地，没有任何文字。

系统开「减少动态效果」时，刊头浮动和所有过渡都停掉（`animation: none; transition: none`），进度飞机只跟随滚动位置、不做补间。

## 插画：跟着句子走

统一一种笔触：单色墨线（`#2b2824`，深色模式下用 CSS `invert + hue-rotate` 变成暖白线），圆头 1.7px 线，所有画都过一层轻微的 `feTurbulence + feDisplacementMap`，线条带一点手抖。每幅画都是本页原创的 SVG 文件（`art/*.svg`），按句子内容构图；不临摹任何现成插画（包括《小王子》原书插图），不画真实人物肖像，画里的小人都是无脸的简笔人形。

## 音乐

方案和代码沿用第一版：
- 歌：The Walters《I Love You So》，**只用 YouTube 官方嵌入播放器**（`youtube-nocookie.com` 域、IFrame Player API）播放，仓库里**不放任何音频文件**——这是版权上的底线：我们没有这首歌的授权，只能借官方渠道的嵌入播放，由 YouTube 负责版权方的授权和分成。
- **autoplay**：浏览器禁止有声音的 autoplay（自动播放），所以退而求其次——第一次点页面任意处（或按回车/空格）就开始播放；用户主动暂停后，再点页面不会再自动唤醒；iOS 只认在播放器里的直接点击时，状态文字会提示去点播放器。
- YouTube 条款要求播放器可见、不小于 200×200：播放器能放（ready / playing / paused）时，200×200 的播放器框是展开可见的；只有在加载中或连不上时才把这个框收起来，换成一行「去别处听」的链接（网易云音乐 / Apple Music / Spotify / YouTube 搜索）。外网被拦时点开关不会报错。
- 放得更轻：宽屏（≥1360px）收进左下角，不占正文栏；更窄时是标题下方一行小字 + 一个纸飞机按钮。
- 预览时可以用 `?yt=<视频ID>` 临时换视频；播放器就绪后会核对标题/频道里有没有 `walters` 或 `i love you so`，不是就降级，不会放错歌。
