# 微博碎句集 · 设计稿

> 预览地址（本地起静态服务后）：`/_preview/weibo/`
> 线上 `#/weibo` 没动；用户确认设计稿后，再另派实现单把它接进去。

## 1. 视觉方向（先定调，再动手）

**一句话：一本夹在星图里的水彩手账。**

- **浅色＝水彩纸**：暖白纸色 `#f4ecdc`，一层极淡的纸纹噪点，顶部晕一抹灰蓝天色、右下晕一抹杏色暮光，像水彩纸上没干透的颜料。
- **深色＝夜空**：靛蓝 `#0f1626`，顶部有一团更亮的蓝色星云，满屏 46 颗会慢慢闪的小星（其中几颗是四角星芒）。文字是旧纸的米白 `#ebe2cf`。
- **点缀色只用三种**：玫瑰红（小节编号、链接、状态文字）、星光金（星饰、题记括号）、天蓝（个别星饰）。
- **字**：霞鹜文楷（楷书风，带手写温度，开源 OFL），全页一款字，靠字号、字距、颜色分层，不靠加粗。
- **插画**：原创的「小星球」系列——一颗星球一个故事：玫瑰、狐狸、猴面包树、路灯、落日空椅。墨线微微抖动（SVG 位移滤镜模拟手绘），底色是渗出线外的水彩块。
- **节奏**：每个小节像一页纸——「其一 / 其二…」小红字编号 → 标题 → 一枚金色小圆点饰线 → 『题记』 → 一条条碎句。每两三个小节之间翻过一幅插画。

参考的是「小王子那种感觉」：小星球、孤独又温柔、留白多。**没有**临摹原书任何一幅插图，**没有**画那个金发小男孩，**没有**用书名或商标（详见第 3 节）。

## 2. 版式与中文排版

| 项 | 取值 | 为什么 |
|---|---|---|
| 正文行宽 | `40rem`（16px 根字号下 640px，≥1600px 屏根字号 18px → 720px；2560 宽实测 720px） | 一行约 36 个汉字，长句不累眼 |
| 正文字号 / 行距 | 17px / 2.0（手机 16px / 1.95） | 楷体笔画细，行距要比黑体再松一点 |
| 对齐 | `text-align: justify` + `text-justify: inter-character` | 中文两端对齐，右边缘整齐 |
| 禁则 | `line-break: strict` | 「，。！？」等不出现在行首 |
| 标点挤压 | `text-spacing-trim: normal`（Chrome 123+）；`hanging-punctuation: allow-end`（Safari） | 行首开引号、相邻全角标点挤掉半格；行尾句号悬挂 |
| 中西文间距 | `text-autospace: normal`（Chrome 140+；不支持的浏览器保持原样） | 「顺序是 bright」里自动留 1/8 em，不改原文 |
| 长英文串 | `overflow-wrap: anywhere` | 手机上不撑破屏幕 |
| 小节标题 | 26px、字距 .16em，上方 13px 玫瑰红「其一」（CSS counter `cjk-decimal`），下方金点饰线 | 编号、饰线都在 CSS 伪元素里，**不往正文里塞字** |
| 引用块（每节题记） | 15px 居中、灰褐色，左右一对金色『』（伪元素，屏幕阅读器不读） | 题记要轻，跟正文拉开层级 |
| 碎句（列表项） | 去掉圆点，左侧悬挂一颗 CSS 画的四角小星（金 / 红 / 蓝轮换），片段间距 1.35em | 一条微博就是一个独立片段 |
| 序言「按」 | 一张微微倾斜的小信笺卡片，`white-space: pre-line` 保留原文换行 | 「另，不后悔炸号。」单独成行，语气才对 |
| `&nbsp;` 空段 | 保留在 DOM 里，只把高度收成 0 | 正文一字不改；小节间距由版式控制 |

**正文怎么来的**：`app.js` 现场 `fetch('../../weibo.md')`，用仓库里的 `vendor/marked.min.js`（v12）渲染进 `[data-weibo-body]`。渲染后只做三件事：把每个 `h2` 连同后面的内容包成 `<section class="chapter">`（节点原样搬）、给空段加 class、在第 2 / 4 / 7 节后插入装饰插画（`alt=""`、`aria-hidden`，不产生文字）。自检：渲染后的文字去掉空白与 Markdown 标记后，和 `weibo.md` 逐字相等（7133 字）。

**字体**：霞鹜文楷 Lite（LXGW WenKai Lite，SIL OFL 1.1，许可证见 `fonts/OFL.txt`），按 `weibo.md` + 页面界面用到的字子集化成一个 `fonts/wenkai-weibo.woff2`（约 332KB）。`weibo.md` 以后新增的生僻字会回落到系统楷体 / 宋体，不会显示方块；接入正式页面时重跑一次子集脚本即可。

**体积**：整页同源传输约 470KB（字体 332KB、weibo.md 21KB、marked 35KB、页面与 5 幅 SVG 共约 50KB），远低于 3MB。

## 3. 插画（全部原创）

| 文件 | 内容 | 位置 |
|---|---|---|
| `art/rose-planet.svg` | 小行星上一枝玫瑰、一座冒烟的小火山、弯月 | 页首 |
| `art/baobab.svg` | 小星球上三棵胖乎乎的猴面包树 | 其二之后 |
| `art/fox.svg` | 麦草坡上的小狐狸，仰头看一颗星 | 其四之后 |

| `art/sunset-chair.svg` | 小星球上一把空椅子，对着远处的落日 | 页尾 |

- 每一条路径都是为这页手写的 SVG 坐标，画风是「墨线抖动 + 水彩渗色」，和原书的铅笔淡彩构图、角色造型都不同；**画面里没有任何人物**，避免与原书主角形象相近。
- 页面和插画里都不出现原书书名、作者名或任何商标。
- 每幅 SVG 自带 `prefers-color-scheme` 配色：浅色是墨线 + 水彩，深色换成米白线条 + 更亮的星光。

## 4. 音乐：The Walters《I Love You So》

### 4.1 两条硬限制

1. **版权**：这首歌受版权保护。**仓库里不放任何音频文件**（`_preview/weibo/` 下只有 HTML / CSS / JS / SVG / 字体）。只能用官方平台的嵌入播放器，或者链接过去听。
2. **自动播放**：Chrome、Safari、Firefox、Edge 都禁止「有声音的自动播放」——页面一打开就响**做不到**，任何网站都一样。能做到的最近体验是「**第一次碰页面，歌就开始**」。

### 4.2 来源方案对比

| 方案 | 能放多少 | 主要条款 / 限制 | 国内能否打开 | 可编程控制 | 评价 |
|---|---|---|---|---|---|
| **A. YouTube 官方视频嵌入**（IFrame Player API，`youtube-nocookie.com`） | 整首 | 播放器**必须可见**、不小于 **200×200 px**，不能用 CSS 隐藏、遮挡或缩成背景音乐；不能去掉 YouTube 标识；广告由 YouTube 决定；必须用官方/有权上传者的视频 | 不能（需翻墙） | 可以：`playVideo / pauseVideo`，状态回调、错误回调都有 | **推荐**。唯一「不登录也能听整首 + 能用自己的唱片按钮控制」的合法方案 |
| B. Spotify 嵌入（Embed / iFrame API） | **未登录只能听 30 秒预览**；登录 Spotify 后整首 | 必须用官方嵌入外观，不能改样式、不能隐藏 | 基本不能 | 有 iFrame API（play/pause），但未登录仍是 30 秒 | 适合海外、有 Spotify 账号的访客；作为 A 的备选 |
| C. Apple Music 嵌入（`embed.music.apple.com`） | 未登录 / 非订阅用户 **30 秒预览**；订阅用户登录后整首 | 必须用官方嵌入卡片 | 能打开，但多数人不会登录 Apple Music 网页版 | 嵌入卡片不提供可靠的外部控制 API | 不推荐做主方案 |
| D. SoundCloud 嵌入（Widget API） | 取决于版权方是否在 SoundCloud 上传整首；很多主流单曲只给 30 秒或不可嵌入 | 只能嵌入版权方开放的音轨 | 不稳定 | 有 Widget API | 需要先确认 The Walters / 厂牌有官方可嵌入音轨，不确定性大 |
| E. 网易云音乐 / QQ 音乐外链播放器 | 有版权且开放外链时可整首；不少欧美曲目外链被关 | 版权方随时可能下架或禁外链；需要确认曲目在国内有正版授权 | 能 | 外链播放器基本不能外部控制 | 适合国内访客，但能不能嵌要逐首确认，**本稿只放链接** |
| ✗ 把 mp3 放进仓库 / 第三方搬运源 / TikTok 剪辑 | — | 侵权；TikTok 嵌入只是带片段的视频，不是完整歌曲 | — | — | **不做** |

**推荐：A（YouTube 官方嵌入）做主播放器 + 降级卡片里放 网易云 / Apple Music / Spotify / YouTube 的官方搜索链接。**
理由：只有 A 能让「没登录任何音乐账号」的访客听到整首，并且能挂在我们自己设计的唱片按钮上；B / C 未登录只有 30 秒，体验断崖。代价是国内访客打不开 YouTube——所以降级卡片优先放网易云（国内能开）。如果用户更在意国内访客，可以改成「E 为主、A 为辅」，但要先确认这首歌在网易云有正版且允许外链。

### 4.3 交互：最接近「进来就放」的设计

页首下方是一张「留声机」卡片 `[data-music]`：左边一张黑胶唱片按钮 `[data-music-toggle]`，中间歌名 / 艺人 / 状态，下面是**可见的** YouTube 播放器（≥200px 高，符合条款）。往下读的时候右下角有一枚小唱片悬浮按钮，同样能播放 / 暂停。

1. 页面打开就在后台加载 YouTube 播放器（不出声）。状态写「唱针已经备好，轻触页面任意处，歌就开始」。
2. **用户第一次在页面任何地方点一下 / 按回车或空格**，就调用 `playVideo()`，唱片开始转。
3. 再点唱片 = 暂停；主动暂停后，再点页面别处不会把歌又叫起来。
4. 调用播放 2.5 秒后还没响（典型是 iOS Safari），状态改成「浏览器拦下了自动播放，请直接点一下播放器里的播放键」。
5. 播放器就绪后核对视频标题 / 频道里是否含「Walters」或「I Love You So」，**不是这首歌就不放**，直接降级——宁可不放，不放错歌。
6. 「减少动态效果」打开时唱片不转、星星不闪，播放功能不受影响。

### 4.4 各浏览器的实际表现（按公开的自动播放策略）

| 浏览器 | 打开页面时 | 第一次点页面后 |
|---|---|---|
| Chrome / Edge（桌面、安卓） | 不出声（有声自动播放被禁） | 能放。父页面有了用户激活，API 创建的 iframe 自带 `allow="autoplay"`，`playVideo()` 生效 |
| Firefox（默认「阻止音频」） | 不出声 | 能放（点击算用户手势） |
| Safari（macOS） | 不出声 | 大多数情况能放；个别版本只认在播放器里的直接点击，此时页面会提示去点播放器 |
| Safari（iOS / iPadOS），以及 iOS 上所有浏览器 | 不出声 | **经常放不了**：iOS 基本只认在 YouTube 播放器里的直接点击。页面 2.5 秒后提示「请直接点一下播放器里的播放键」 |
| 微信内置浏览器（国内） | YouTube 打不开 → 降级卡片 | — |

### 4.5 外网被拦时的降级

- 加载 `https://www.youtube.com/iframe_api` 失败（`onerror`）、9 秒内播放器没就绪，或播放器回调报错（视频不可嵌入 / 不存在）→ 卡片切到 `data-state="offline"`：唱片变灰，播放器区域换成一张虚线卡片「唱片机这会儿连不上（可能是网络或地区原因），换个地方听也一样」，下面是网易云音乐、Apple Music、Spotify、YouTube 的官方搜索链接（新窗口打开）。
- 全程 `try/catch`，不抛 JS 异常，不弹窗，正文照常显示。浏览器控制台里只会有一条「资源加载失败」的网络日志——这是浏览器自己打的，页面拦不住，也不影响使用。
- 云端截图环境里 YouTube 正好被拦，所以下面的截图展示的就是降级状态。

### 4.6 待核对（重要）

- `app.js` 里的 `DEFAULT_VIDEO_ID` 写的是 `ZtDDXF_VfZE`。做设计稿的云端环境连不上 YouTube，**没法核实这个 ID 确实是 The Walters 官方频道的《I Love You So》**。
  - 已经做了保护：播放器加载后会核对标题 / 频道，不对就降级，不会放错歌。
  - 核对方法：在能上 YouTube 的网络里打开预览页，看播放器里是不是这首歌；不对的话，到 The Walters 官方频道（或厂牌官方 / YouTube Music 自动生成的「Topic」频道）找到这首歌，把 11 位视频 ID 填进 `DEFAULT_VIDEO_ID`。预览时也可以直接在网址后加 `?yt=<视频ID>` 试。

## 5. 明暗、手机、动效

- **明暗**：只跟随系统 `prefers-color-scheme`，没有手动开关（设计稿阶段先不加，接入时可以跟主站的语言切换按钮放一起）。
- **手机 390 宽**：所有块宽度 `calc(100% - 2.5rem)`，唱片缩到 88px，长英文串可断行；实测 `scrollWidth = 390`，无横向溢出。
- **减少动态效果**：`@media (prefers-reduced-motion: reduce)` 下把所有元素的 `animation` / `transition` 设为 `none`；实测 `document.getAnimations().length === 0`。页面没有任何 JS 驱动的动画。
