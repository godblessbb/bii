## 做了什么

在 `_preview/webgl/` 里做了一整版「沉浸式 WebGL」的 datode.com。入口是 `_preview/webgl/index.html`，没有构建步骤，库全部放在目录里。仓库根目录和别的文件一个字节都没动。

**整体结构**
- `js/gl.js`：自己写的 WebGL 1 场景，没用 three.js，大约 20 KB。用了两块画布：
  - `#scene` 常驻在背景。底层是全屏噪声地形：用域扭曲的 fbm 做出流体般的色带，叠上会随滚动推移的等高线和胶片颗粒。上面是 16,000 颗粒子，手机上是 6,500 颗。粒子在 4 种「形」之间插值：A 是「菜花」字形，B 是头像线稿，C 是作品页的声环，D 是漂移的星野。
  - `#veil` 只在切换栏目时出现，做液态溶解转场：噪声场做阈值推进，边缘带一道青柠色和一道余烬橙的光。
- `js/app.js`：hash 路由、中英文案、Markdown 渲染（`vendor/marked.min.js`）、工具画廊、Rapstar 音频可视化。
- `css/site.css`：明暗两套配色，「减少动态效果」时整套关掉动画。

**各栏目**
- **首页 `#/`**
  - 首屏是一整屏实时场景，粒子聚成「菜花」两个字。手机竖屏上改成上下叠排。
  - 鼠标移动会把粒子推开，被推开的粒子从青柠色变成余烬橙，背景的流体也会跟着打旋。
  - 滚动推动场景演进：字形散成星野，经过封面文案（取自 `_coverpage.md` 的三条），再经过四个大字号入口，最后粒子重新聚成头像线稿。
  - 左下角有一行等宽字的「遥测」：场景名、鼠标坐标、粒子数。
- **文章 `#/articles`**
  - 学习笔记、随笔杂文、微博存档分成 3 组，可以按标签筛选。8 篇的链接都写成 `#/<路径>`。
  - 进入文章后背景场景**完全停下并藏起来**，正文落在纯色底上，字号 18px、行高 1.95，宽屏有目录、顶上有阅读进度条。
- **工具 `#/tools`**
  - 电脑上是一片可拖拽的空间画廊：9 个玻璃透镜球按景深散在 1900×1250 的平面上，带惯性。拖动和滚动时，近处的球漂得快、远处的慢。
  - 鼠标悬停时，透镜上会叠一层 SVG `feTurbulence` + `feDisplacementMap` 做折射扭曲。
  - 点击进站内外框 `#/tools/<名字>` 用 iframe 打开，也可以新窗口打开。共享剪贴板 clip.gpubuy.com 是外链。
  - 手机上画廊变成左右交错的竖向漂流，随滚动轻轻摆动。
- **作品 `#/works`：Rapstar 专题，没有做成小卡片**
  - 巨型渐变字标「Rapstar」。
  - 粒子组成的声环包着一张 CSS 黑胶唱片，外面一圈 96 根放射状的频谱条。
  - **点了才响**：用 Web Audio 的 AnalyserNode 取低频能量，同时驱动频谱条、声环的波动、粒子变色和背景亮度。
  - 下面还有曲目列表、「它由三样东西组成」、描边大字的曲目单、超大的「进入 Rapstar →」。
  - 页面上没有任何 mahjong 或 04bot 的链接或文字。rapstar 自带的分享卡图片印着 04BOT 字样、底色偏紫，所以没用。
- **关于 `#/about`**
  - 渲染 README.md。电脑上粒子在右侧聚成头像，正文在左；手机上头像在上、正文在下。
- 旧链接 `#/weibo`、`#/README`、`#/_weibo/weibo0`、`#/_study/…`、`#/_works/…`（包括 URL 编码的中文文件名）都能打开对应文章。

**设计说明**

参考站（Awwwards / FWA / CSSDA），以及从每个借了什么：
1. Lusion 的工作室官网，lusion.co（Awwwards 2019 年 5 月月度最佳，https://www.awwwards.com/case-study-for-lusion-by-lusion-winner-of-site-of-the-month-may.html）。借了「首屏就是实时场景、鼠标直接搅动它」的做法：粒子被推开时变色升温，背景流体跟着打旋。
2. Unseen 做的 BlueYard（Awwwards 当日最佳，也拿过 FWA / CSSDA，https://unseen.co/projects/blue-yard/）。上万颗粒子组成星云，并在不同形态之间聚散。借了「同一批粒子贯穿全站、换栏目只是换形」：字形、星野、声环、肖像共用一批粒子。
3. Bureaux 做的 Igloo Inc（Awwwards 2024 年度网站，https://awwwards.com/igloo-inc-case-study.html）。借了用滚动推进场景叙事（首页从字形散开再聚成头像），以及等宽小字的仪表盘式标注（左下角遥测、`01 / 04` 编号）。
4. Ronin161 的 WebGL Transition（Awwwards 元素收录，https://www.awwwards.com/inspiration/webgl-transition-ronin161-2）。借了栏目之间用着色器做扭曲转场，而不是淡入淡出。这里做成噪声阈值推进的液态溶解，边缘带双色光。
5. House of Dreamers 的 Page Transition（Awwwards 元素收录，https://www.awwwards.com/inspiration/page-transition-house-of-dreamers）。借了流体跟随鼠标、转场带液态边缘的手感，用在背景域扭曲和转场遮罩上。

字体：
- 拉丁字展示用 Unbounded（宽体、几何，适合巨型字标和栏目名）。
- 中文正文和标题用 Noto Sans SC，外引 Google Fonts，分片按需加载，不自托管整包。
- 等宽字用 JetBrains Mono。
- 外网拦掉后，依次回退到 PingFang SC、Hiragino Sans GB、Microsoft YaHei、系统无衬线体和 ui-monospace。
- 粒子字形用的是自托管的 1.3 KB 子集，只含「菜」「花」两个字（Noto Sans SC Black，OFL 授权），保证任何系统上都能聚出同一个字形。

配色（都不是紫色；亮色单独调过，不是反色）：
- 暗色（主场）：近黑的苔藓底 `#060807`，菜花绿（荧光青柠）`#c4ff3a`，余烬橙 `#ff6a3d`，骨白 `#e8efe4`。粒子用叠加混合，会发光。
- 亮色：灰绿粉笔底 `#e7eae2`，叶绿墨 `#1f6b14`，信号橙 `#ff5418`。粒子用正常混合、颜色更深，像墨点。着色器也有一套亮色专用的底色、流体色和暗角色。

动效清单：
- 首屏粒子聚字。
- 鼠标推开粒子并升温变色。
- 背景域扭曲流体，加上等高线。

- 栏目之间的液态溶解转场。旧画面会留一层残影被遮罩盖住，新内容此时已经在 DOM 里。

- 透镜悬停时的 SVG 折射。

## 决定
- 自己写原生 WebGL 1，没引入 three.js。也考虑过把 three.js 放进 vendor（约 600 KB），但这一版只需要全屏着色器、点精灵和一层转场，原生实现大约 20 KB，首页同源总共才 200 KB 左右，手机上也更轻。
- 粒子数电脑 16,000、手机 6,500，再加自适应降分辨率。也考虑过固定数量，但掉帧时自动降分辨率对弱显卡更稳。
- 首屏聚的是「菜花」两个字，头像留到滚动的终点和关于页。也考虑过首屏直接用头像，但字形是网站名，辨识度更高；头像放在最后出场更像一个落款。
- 粒子字形用 1.3 KB 的自托管两字子集。没有依赖系统字体，是因为系统可能没有中文黑体，会聚出方块；1.3 KB 也远不算「整包自托管」。
- 头像粒子按亮度梯度（线稿）撒点，深色块只撒一层薄雾。按暗度直接撒点会让头发变成一团黑块，认不出眼镜和五官。
- 背景是域扭曲的流体加等高线。也考虑过纯星空或纯网格；等高线给了「地形、空间」的质感，又不抢粒子的戏。
- 转场是液态噪声溶解，新内容立刻进 DOM，旧画面留一层残影被遮罩盖住。最早的写法是「先盖住、再换内容」，但那样切换后 0.3 秒内 DOM 还是旧的，自动化验收或读屏会读到旧页面。
- 工具画廊的透镜**静止时不动**，只在拖拽或滚动时漂移、有惯性。最初做了常驻的轻微浮动，但自动化点击会因为「元素一直在动」而超时，常驻浮动对点按也不友好。合同写的是「可拖拽**或**随滚动漂移」，现在两样都有。
- 手机上的工具画廊改成竖向交错漂流，不能拖。手机上拖整块画布会和页面滚动抢手势。
- 作品页没用 rapstar 目录里的封面卡 PNG，改用 CSS 黑胶唱片配「飽」字标签。那些 PNG 是横版分享卡，印着「RAPSTAR · 04BOT」，底色偏紫，和「页面上不出现 04bot」以及「不用紫色」相冲。
- 声音只在点击播放后才响，离开作品页自动停。播放后低频能量同时驱动频谱、声环、粒子颜色和背景亮度，让「音频可视化氛围」覆盖整屏，而不只是一个小控件。
- 进入文章阅读时，背景场景完全停下并隐藏。也考虑过把场景调暗了继续跑，但长文（weibo.md、5 万字转载）要求零额外开销。
- 关于页的 `#/README` 走文章视图，`#/about` 走带粒子头像的版式。两者内容相同，旧链接行为和上一版一致。
- 栏目编号「01 / 04」、遥测小字、「◆」标记都用等宽字，模仿仪表盘的感觉；全站不用全大写。
- 英文模式下，切换按钮仍显示「中 / En」两个字样，回退大字「菜花」保留中文，因为它是品牌字形。
- 明暗只跟随系统，没有做手动切换按钮。合同只要求跟随系统；多一个按钮还会和语言切换挤在手机顶栏上。

## 残留风险
- 平台验收脚本 `datode_variant_check.py` 在云端不存在，没法原样跑。我按合同条文写了等价自测并全部通过，但脚本的具体判法（比如等多久、点哪个元素、英文残留的判定范围）可能和我的理解有出入，以用户机器上的结果为准。
- 容器里的 Chromium 只能走 SwiftShader 软件渲染，帧率只有个位数，所以**没能在真实 GPU 和真机手机上验证流畅度**。降级策略（粒子减量、隔帧、DPR 上限、自适应降分辨率、转场看门狗）都写了，但真实设备上的手感需要人看一眼。
- 断网时 Google Fonts 加载失败会在控制台留下「Failed to load resource」，Google Analytics 同样会留下。这是合同允许的外部资源，但如果验收把所有控制台 error 都算作报错，会被这两条误判。
- 有两处画面效果只在部分浏览器里有：悬停折射用的是 SVG 滤镜，`color-mix()` 用于半透明配色。老浏览器（Safari 16.2 以前）不认 `color-mix` 时，那几处会退成没有底色或透明，不影响内容。
- 音频分析用 Web Audio 的 `createMediaElementSource`。如果有人在某些移动浏览器上把页面挂到后台，回来后可能需要再点一次播放，这是浏览器策略。
- 工具 iframe 外框直接嵌入原工具页。原工具页里自带的第三方脚本（比如 rapstar 页面自己的 GA）不归这一版管。
