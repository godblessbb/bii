## 设计方向
「动态字体 / 新粗野」：以字为主角——超大可变字体随滚动和鼠标实时变形（字重、宽度、倾斜、拉伸），首屏是一句会动的巨型文字装置；硬边网格、裸露的结构线、大面积纯色块与强对比，配一个高饱和强调色（荧光黄绿、信号橙这类，不许紫）；横向滚动的栏目条、无限跑马灯、反色光标、点击和悬停有干脆的切换而非柔和渐变；文章列表做成目录表/索引式排版而不是卡片。英文展示字体可以把一款开源可变字体子集化后放进目录（注意体积），中文用系统字体加粗重排。

用户的原话是「设计上一定要炫酷」，上一版（杂志风、米白朱砂、逐字升起）被嫌不够酷——**不要做成上一版的换皮**。动手前先找 3–5 个与本方向对口的 Awwwards / FWA / CSS Design Awards 获奖站当参考（报告里列出链接和你从每个借了什么）。

## 硬性要求（下面每条本机验收都会判）
1. 纯静态、不要构建步骤，推到 GitHub Pages 就能发布。用到的 JS/CSS 库一律下载进 `_preview/kinetic/` 下（例如 vendor/），不从 CDN 加载。外网全部被拦掉时页面必须照常工作、没有 JS 报错、没有同源 404。网页字体可以引外部，但拦掉后要有合适的回退；中文字体不要自托管整包（首页同源传输量上限 3MB）。index.html 里保留 Google Analytics（G-7DEXQT23DE）。
2. 文章内容一字不改：仓库根的所有文件都不许动（包括 README.md、weibo.md、_study/、_weibo/、_works/、IMG_0205.PNG、CNAME、index.html、assets/、工具页、rapstar/ 等）。页面在浏览器里取这些 .md 渲染（markdown 解析器同样放进你的目录）。
3. 旧链接继续能打开：在 `_preview/kinetic/` 下，`#/weibo`、`#/README`、`#/_weibo/weibo0`、`#/_study/<文件名>`、`#/_works/<文件名>`（中文文件名，URL 编码后也要能打开）都要渲染对应文章。
4. 工具页只统一入口：工具页本身一个字节都不许动，入口和外框在新站的工具栏目里做。
5. 手机 390 宽每个页面都不能横向溢出；电脑和手机都要好看，重效果在手机上要降级到不卡。
6. 系统开了「减少动态效果」（prefers-reduced-motion: reduce）时关掉所有动画：CSS 动画、Web Animations、JS/canvas/WebGL 驱动的动效、平滑滚动、鼠标跟随都要停，改成静态画面（不是黑屏或空白）。
7. 明暗跟随系统（prefers-color-scheme），两种模式页面底色要明显不同、都精心配色，不是简单反色。
8. 中文为主，带英文切换：页面上放一个带 `data-lang-toggle` 属性的切换按钮，切换时设置 `<html lang>`（默认 zh-CN，切换后 en），选择存 localStorage、刷新后保持。英文模式翻译所有界面文字（导航、栏目名、首屏、工具和作品的介绍、文章标题），文章正文保持中文原文。
9. 风格禁区：不用紫色做主色；标题和导航不用全大写（不许 text-transform: uppercase，英文也不要写成全大写字面）；不要满屏铺卡片。
